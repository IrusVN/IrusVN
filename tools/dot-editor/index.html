ANIMATION
Xem thử mô phỏng chuyển động của các band trên chính lưới dark đang nạp (không phải render SVG thật). Bấm “Áp dụng” để tải banner_config.json đặt vào repo root, hoặc “Copy lệnh” để lấy lệnh chạy banner.py kèm tham số.
BANNER THAT
Đây là dark.svg / light.svg thật (SMIL chạy trong <img>) lấy từ repo root — tức là bản trên đĩa. Sau khi sửa lưới: Export .npy → chép đè vào repo → python3 .github/scripts/banner.py --from-npy → mở lại dialog này.
⚠ Lưới trong editor có thay đổi chưa export — SVG dưới đây chưa phản ánh chúng.
